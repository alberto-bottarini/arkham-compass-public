Leurre Piégé

Événement Survivant 2

Piège. Ruse.

Rapide. À attacher à votre lieu. Limite de 1 Trap par lieu. Après qu'un ennemi est entré dans le lieu attaché, inclinez le Leurre Piégé : Échapper à ( ou ). Échappez à cet ennemi. Vous gagnez +1 à votre valeur de compétence pour cette évasion. Si ce test est réussi, vous avez le droit de défausser le Leurre Piégé pour vous déplacer vers ce lieu. (Vous avez le droit de déclencher cette capacité depuis n'importe quel lieu.)
